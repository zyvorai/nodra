Zyvor·NodraEdge runtime · Offline-first

The cloud is gone. The site keeps running.

Open edge runtime with local MQTT/HTTP ingress, durable store-and-forward, device twins, and a clean control plane. WAN loss is a first-class mode.

INGEST1

Devices publish

PLC, sensor or app hits nodrad over MQTT 3.1.1 or HTTP — no cloud hop required.

LOCAL2

Routes stay live

Topic filters deliver to MES, local AI and apps on the site while the WAN is down.

SPOOL3

Nothing is lost

Append-only fsynced WAL with explicit backpressure: reject, drop-oldest or drop-newest.

RETURN4

WAN comes back

The edge catches up to the control plane. Event time is preserved separately from ingest time.

DELIVER5

Cloud & recover

Cloud routes, device twins, and a replayable dead-letter queue when delivery fails.
